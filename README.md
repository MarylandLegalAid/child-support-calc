# Maryland Child Support Calculator

A Windows desktop app for Maryland Legal Aid staff. It calculates the child support guideline amount under
Md. Code, Family Law §12-204, live as you type, and exports a worksheet PDF laid out like the official Maryland
Judiciary forms:

- **Worksheet A** (CC-DR-034), sole/primary physical custody — §12-204(l)
- **Worksheet B** with **Worksheet C** (CC-DR-035), shared physical custody — §12-204(m)

Two guideline versions: **October 2025** (current law, with the multifamily adjustment of §12-201(c)(1)(iii)) and
**July 2022** (the same law without it, for periods before October 1, 2025).

The calculation follows the statute and the official worksheets. The arithmetic is specified line by line in
`docs/calculation.md`, judgement calls are in `DECISIONS.md`, and sources are in `PROVENANCE.md`.


## Layout

```
MdChildSupport.slnx

samples/                         example case files (shared and sole custody)

```

## Build, test, run

Requires the .NET 10 SDK on Windows. Without a brand folder the app builds with neutral placeholder branding; for the
official look, put Maryland Legal Aid's brand folder at `branding/local/` (see `branding/README.md`).

```bash
dotnet run --project tests/MdChildSupport.Core.Tests
```

```bash
dotnet build src/MdChildSupport.App -p:Platform=x64
```

```bash
dotnet publish src/MdChildSupport.App -c Release -r win-x64 -p:Platform=x64 -o publish/win-x64
```


## What is tested

- The embedded schedule equals §12-204(e) in the statute text on every row, column and asterisk.
- 28 worked cases in `tests/cases/` (sole custody both ways, shared custody at 92, 94, 95, 98, 99, 102, 103, 105,
  106, 109, 110 and 183 overnights, alimony both ways, pre-existing support, every expense type paid by each parent,
  cash medical, multifamily, schedule row edges, top of and above the schedule, zero and negative income, the
  §12-204(m)(5) limit, overnights below 92, no children). They are generated by an independent Python
  implementation (`tests/cases/tools/worked.py`) that shows the arithmetic of every line.
- Properties over thousands of random cases: swapping the parents swaps every result; shares total 100% ± 0.1;
  support never rises when the payer's own deductions rise; July 2022 = October 2025 when no multifamily amount.
- The PDF contains every engine line value in order, the caption, children, notes, footer; long text wraps on the page.
- Case files round-trip exactly.

## Using the app

- Every edit recalculates. The **Review** box lists anything the preparer should look at; every warning is also
  printed on the worksheet.
- **Multifamily** (calculator button by each parent's amount): enter the number of additional children in that
  parent's home; *Apply* fills the amount (schedule amount at that parent's actual income × 75%) and adds a
  footnote showing the arithmetic. You can type a different amount (§12-201(c)(3)).
- **Comments** print under "Comments or special adjustments".
- Cases save as `.mdcase` (JSON, `docs/file-format.md`). **Export Worksheet PDF** (Ctrl+P) writes and opens the PDF.
- The worksheet footer line is set in `MdChildSupport.settings.json` next to the executable (its default comes from the
  brand folder).
