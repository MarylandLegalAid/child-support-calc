# Worked cases

Each `*.md` file is one case: the inputs (a complete `.mdcase` JSON block), the arithmetic of every worksheet line,
and an **Expected** table with the result and the Review warning codes. `WorkedCaseTests` loads every file and checks
that the C# engine produces exactly the same lines, values, result and warnings. `PdfTests` checks that each case's
values appear in the exported PDF in order.

The files are generated by `tools/worked.py`, a second implementation of `docs/calculation.md` written separately
from the C# engine, so the two act as a cross-check. Every step is printed so that a reviewer can redo it with pencil
and paper from the official form's instructions. To regenerate after changing the spec:

```bash
python -I tests/cases/tools/worked.py
```
